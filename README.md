## 📌 About the Project

**Xenly** is a full-stack social media web application that replicates the core experience of platforms like Facebook. It offers a clean, responsive UI along with a robust admin panel for platform moderation and analytics — making it a great showcase project for modern React + Firebase development.

🌐 **Live App:** [xenly.vercel.app](https://xenly.vercel.app/)
📦 **Source Code:** [github.com/devsujoydas/xenon-media-v2-client](https://github.com/devsujoydas/xenon-media-v2-client)

---

## 🚀 Features

### 👥 User Features

- 🔐 JWT Authentication (Email/Password)
- 📝 Create, update, and delete posts
- ❤️ Like posts and 💬 comment on them
- 📤 Share posts with others
- 👥 Follow Unfollow
- 🔍 Search for users and posts
- 🧾 View and edit your own profile
- 📷 Upload and update profile pictures
- 💾 Save posts for later
- 🔒 Protected routes for authenticated users only
- 🔃 Smooth scrolling and a fully responsive UI (mobile-first)

### 🛠 Admin Features

- 📊 Analytics dashboard with visual charts (users & posts)
- 🧑‍💻 Manage users — view and delete accounts
- 🗑 Moderate posts — review and remove content
- 🔧 Role-based, admin-only protected routes

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | React 19, Vite |
| **Styling** | Tailwind CSS 4 |
| **Authentication** | JWT Authentication |
| **Database / Storage** | MongoDB |
| **Routing** | React Router DOM v7 |
| **State Management** | React Query, Context API |
| **Forms** | React Hook Form |
| **Charts** | Chart.js, react-chartjs-2 |
| **UI Components** | SweetAlert2, React Icons |
| **Notifications** | React Hot Toast, React Toastify |
| **UX Enhancements** | Lenis (smooth scroll), match-sorter |
| **Deployment** | Vercel |

## ⚙️ Getting Started

Follow these steps to run Xenly locally on your machine.

### ✅ Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### 🔄 Clone the Repository

```bash
git clone https://github.com/devsujoydas/xenon-media-v2-client.git
cd xenon-media-v2-client
```

### 📦 Install Dependencies

```bash
npm install
```


### ▶️ Run the Development Server

```bash
npm run dev
```

The app will be available at `http://localhost:5173` by default.

### 🏗️ Build for Production

```bash
npm run build
```
